Rules
Sentence case everywhere. UPPERCASE only for mono overlines and the live/frozen mode label. Tracking: −1% on 15px+ titles, +8% on overlines, +6% on mode labels, 0 elsewhere. Truncate, never wrap, in chrome. Toolbar, chips, status line, ids, hierarchy rows: one line with an ellipsis at the end. Wrap prose. Comments, error bodies and empty-state copy use text-wrap: pretty with a max of ~60ch. Numbers in mono, even inside SF sentences: "Sent 3 annotations" is fine as SF; coordinates and ids never are. Minimums: 10px for anything read, 9.5px for tags on fills, 8.5px only on rulers. Errors say what to do. Title states the fact, body gives one next action, the footer is the raw diagnostic in mono-meta. No marketing voice. No exclamation marks, no "Oops", no emoji. Use verbs on buttons: Boot, Retry, Send.
